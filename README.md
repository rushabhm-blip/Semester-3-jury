# Semester 3 Jury

A zoomable, Prezi-style jury presentation on a dot-grid canvas, covering three projects in talk order:

1. **The Fear Between Us** — data storytelling
2. **Time Wanderers** — multimodal interaction
3. **Saath** — Design Project 2, mixed reality

## View it

Open `jury-presentation.html` from a local web server (images load by relative path), for example:

```
npx serve .
```

## Controls

- Click a frame to zoom in; click again or click empty canvas to zoom out
- `→` / `Space` next, `←` previous, `Esc` overview, `F` full screen
- Scroll to zoom, drag to pan

## Images

- `img/c/` — crops from the Saath Figma file and project assets
- `img/tw-*.png` — Time Wanderers slides
- `img/fear-*` — The Fear Between Us illustrations
- `img/gen-intro.png` — intro illustration (ChatGPT), added when ready
